## 🚀 About Me
I'm passionate about both Software Engineering and Cybersecurity.

With a background in Backend Development using Java Spring Boot and Microservices, I have built scalable backend systems while gaining a deep understanding of application architecture, APIs, databases, and distributed systems.

Alongside software development, I actively study and practice Security Operations (SOC), Threat Detection, Incident Response, and Threat Intelligence. I enjoy understanding how modern systems work, how they are attacked, and how to build effective detection and defense capabilities.

I believe that combining development knowledge with security enables me to design more secure systems and better analyze security incidents.
